# Privacy Policy

Last updated: November 5, 2026

## 1. Overview

Obsidian-Rclone is a personal, non-commercial OAuth
configuration used with rclone to synchronize Obsidian
notes between a local computer and Google Drive.

It is intended solely for personal use.

## 2. Google Drive Access

Obsidian-Rclone uses Google OAuth 2.0 to authorize rclone
to access Google Drive.

The read/write configuration requests Google Drive access
that permits reading, creating, modifying, and deleting
files.

Although the granted permission can cover the user's
Google Drive, the current synchronization configuration
targets a specific Obsidian Vault folder.

## 3. How Data Is Used

Google Drive data is accessed only to perform
user-initiated synchronization operations.

These operations may include:

- Listing and reading files
- Downloading and uploading files
- Updating existing files
- Synchronizing file deletions

## 4. Data Storage and Sharing

Synchronization runs locally on the owner's computer
using rclone.

OAuth credentials and tokens are stored locally in the
rclone configuration.

This website does not collect, receive, or store Google
Drive file contents or OAuth credentials.

No separate application server is used to process or
store synchronized files.

Google Drive data is transferred between the local
computer and Google Drive through Google's APIs.

## 5. Data Retention and Deletion

Files remain in Google Drive or on the local computer
until they are deleted by the owner or through an
authorized synchronization operation.

The owner can revoke OAuth access through their
Google Account security settings and remove locally
stored rclone credentials.

## 6. Website Hosting

This information website is hosted by GitHub Pages.
GitHub may process website access information according
to its own privacy policies.

## 7. Contact

For questions about this OAuth application, use the
support email displayed on its Google OAuth consent screen.
