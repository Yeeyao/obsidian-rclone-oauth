# Obsidian-Rclone

Obsidian-Rclone is a personal, non-commercial project
for synchronizing Obsidian notes between a local computer
and Google Drive using rclone.

The application is used only by its owner.

Synchronization is performed locally using rclone.

## About

This website provides information about the OAuth application
used for personal Google Drive synchronization.
